# Sprint 03 — Asset Pipeline + Entity Factory

## Goal
Create the client-side systems that load assets and instantiate entities dynamically.

## Micro-sprints
- 3.1 ResourceManager
- 3.2 EntityRegistry
- 3.3 EntityFactory
- 3.4 WorldManager

## Completion Criteria
- Entity definitions can be loaded from registry data.
- Entities can be spawned without hardcoded preload calls.
- WorldManager can create/update/remove entity nodes from server snapshots.
