# Subindo para o GitHub

```bash
git clone https://github.com/Kyogron/elysium-engine.git
cd elysium-engine
# copie os arquivos deste pacote para dentro da pasta clonada
git add .
git commit -m "Initial Elysium Engine structure"
git push origin main
```

Se o repositório não tiver branch main:

```bash
git branch -M main
git push -u origin main
```
