# Elysium Clash — GDD Outline

## Core Concept
A fantasy MOBA built on Elysium Engine, focused on champions bonded with Eidolons.

## Initial Mode
1v1 one-lane prototype, then 3v3, then 5v5.

## Core Pillars
- Server-authoritative competitive gameplay.
- Distinct champions with Eidolon-based identity.
- Clear readability in combat.
- Ownable art direction, not a clone.

## First Champions
- Loogon
- Kaelyra

## First Map
One-lane proving ground with two bases, towers, minion waves, and simple jungle later.
